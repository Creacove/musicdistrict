## Rules for future screenshots the user supplies
1. Add screenshot to `references/screens` and create a new immutable `V##` in `references/IMAGE_MANIFEST.json`.
2. Identify the *design intent*: proportions, camera, lighting, control hierarchy, component state, physical props and scene mood.
3. Separately flag hallucinated statistics, fake user names, invented prices, unsupported contracts and brand/IP elements.
4. If image seems to contradict accepted gameplay, annotate as a decision request; do not silently prefer the image.
5. Screenshots are never bundled into the player's runtime build; build actual models/geometry and UI.
